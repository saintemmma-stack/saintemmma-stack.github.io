# Instructions for AI assistants

This repository is the website *Second Reading* (Quarto + GitHub Pages).
Before making any change, read `CONTRIBUTING.md` and follow it: structure,
tone, quoting rules, footnote and link conventions, sourcing policy, image
rights and design.

Key rules in short:
- English; scholarly but readable tone; personal remarks as editorial judgement,
  never as invented personal experience.
- Quote speakers briefly with timestamp links; never publish full transcripts here.
- Every factual claim rests on a checked source; only link verified URLs.
- Images only from reusable collections, each with credit and licence.
- Commit on `main`; the site rebuilds automatically.
